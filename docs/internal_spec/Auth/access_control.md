# Специфікація моделі керування доступом (Access Control)

## 1. Обрана модель доступу
У системі реалізовано **Змішану модель керування доступом** (поєднання RBAC та DAC):
* **RBAC (Рольова модель):** доступ надається на основі ролі користувача (`admin`, `user`).
* **DAC (Дискреційна модель):** права на редагування профілю належать його власнику.

## 2. Суб'єкти та Об'єкти
* **Суб'єкти:** `Guest` (неавтентифікований), `User` (користувач), `Admin` (адміністратор).
* **Об'єкти:** `Public Page`, `User Profile`, `System Dashboard`.

## 3. Правила доступу (Матриця прав)
| Роль / Дія | Публічні дані | Власний профіль | Чужий профіль | Адмін-панель |
| :--- | :---: | :---: | :---: | :---: |
| **Guest** | ✅ Дозволено | ❌ Заборонено | ❌ Заборонено | ❌ Заборонено |
| **User** | ✅ Дозволено | ✅ Дозволено | ❌ Заборонено | ❌ Заборонено |
| **Admin** | ✅ Дозволено | ✅ Дозволено | ✅ Дозволено | ✅ Дозволено |

## 4. Принцип перевірки
Перевірка прав виконується **безпосередньо в коді** перед виконанням захищеної операції.
