# Специфікація симетричного криптографічного захисту

## 1. Стратегія захисту даних
* **Алгоритм шифрування:** AES-GCM (256-bit) як стандарт автентифікованого шифрування (AEAD), що гарантує конфіденційність та цілісність даних.
* **Чутливі дані:** Персональні дані користувачів (PII), сесійні токени, збережені конфігураційні секрети.

## 2. Керування ключами та векторами (IV / Nonce)
* **Унікальність IV:** Для кожної операції шифрування генерується новий криптографічно стійкий вектор ініціалізації (`os.urandom(12)`).
* **Заборона повторного використання:** Заборонено повторне використання пари (Key, Nonce) для запобігання атакам відновлення гами.
* **Збереження ключів:** Ключі зберігаються у змінних оточення (Environment Variables) або зашифрованому сховищі секретів.
