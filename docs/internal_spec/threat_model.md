# Модель загроз системи (STRIDE Threat Model)

## 1. Модель порушника
* **Зовнішній неавтентифікований зловмисник:** намагається отримати несанкціонований доступ, перехопити трафік або здійснити DoS-атаку.
* **Легітимний користувач:** намагається підвищити свої привілеї або отримати доступ до даних інших користувачів.

## 2. Аналіз загроз за методологією STRIDE

| Категорія STRIDE | Опис загрози | Компонент системи | Заходи з пом'якшення (Mitigation) |
| :--- | :--- | :--- | :--- |
| **Spoofing** (Підміна) | Підміна сесії користувача через крадіжку токена. | API / Auth Module | Використання короткоживучих JWT Access Tokens (15 хв) та HTTPS. |
| **Tampering** (Фальсифікація) | Зміна даних у запиті під час передачі. | Мережевий трафік | Обов'язкове використання шифрування TLS 1.3 та цифрових підписів токенів. |
| **Repudiation** (Заперечення) | Зловмисник заперечує факт здійснення спроби входу. | Система аудіту | Журналювання подій входу/виходу із зазначенням IP-адреси та часової мітки. |
| **Information Disclosure** (Розкриття) | Витік хешів паролів або персональних даних з бази. | База даних | Хешування паролів за допомогою Argon2id + унікальна сіль (salt). |
| **Denial of Service** (Відмова в обслуговуванні) | Атака перебором паролів (Brute-force) або DoS на форму входу. | Auth Endpoint | Обмеження кількості запитів (Rate Limiting) та тимчасове блокування за IP. |
| **Elevation of Privilege** (Підвищення привілеїв) | Звичайна сесія отримує права адміністратора через підробку токена. | JWT Validator | Валідація підпису JWT на кожному запиті, перевірка ролей (RBAC). |
