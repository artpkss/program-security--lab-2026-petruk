# Специфікація проєкту: Система автентифікації та захисту даних

## 1. Призначення системи
Система призначена для забезпечення безпечної автентифікації користувачів, управління сесіями та захисту персональних даних у вебдодатку.

## 2. Межі проєкту (Scope)
* **Входить до меж:** 
  * Реєстрація та вхід користувачів.
  * Двофакторна автентифікація (2FA).
  * Генерація та валідація JWT-токенів.
* **Не входить до меж:** 
  * Оплата послуг та фінансові транзакції.
  * Інтеграція з зовнішніми соціальними мережами (на першому етапі).

## 3. Вимоги (ISO/IEC/IEEE 29148)
* **Функціональні:** 
  * Система повинна хешувати паролі за допомогою алгоритму Argon2id або bcrypt.
  * Система повинна блокувати обліковий запис після 5 невдалих спроб входу на 15 хвилин.
* **Нефункціональні:** 
  * Час відгуку API автентифікації не повинен перевищувати 200 мс.
  * Усі передані дані повинні шифруватися за допомогою TLS 1.3.![alt text](image.png)
