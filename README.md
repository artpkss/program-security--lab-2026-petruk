# Лабораторна робота №1

## Логування та моніторинг безпеки
* **Формат та кореляція:** Структуровані логи у форматі JSON Lines (`logs/security_audit.jsonl`), мітки часу UTC (`ISO 8601`) та наскрізний ідентифікатор `X-Request-ID`.
* **Рівні:** `INFO` (старт/зупинка, успішний вхід), `WARNING` (помилки входу, недійсні токени), `CRITICAL` (виявлення брутфорс-атак).
* **Захист даних:** Паролі, `client_secret` та повні токени не пишуться в лог (токени маскуються через SHA-256 префікс).
* **Моніторинг та ротація:** Ендпоінт `GET /metrics`, детектор аномалій (≥ 5 невдалих спроб за 60 с з однієї IP), ротація файлів при 5 МБ (до 5 архівів).
